# DRR Test Suite: draft licence terms (v0.9 private beta)

**DRAFT, 2026-10-02. REQUIRES HUMAN REVIEW.** This is prepared for the owner and is not an offer. Nothing here has been sent to anyone. Acceptance, signature and any change of terms are owner decisions (CLAUDE.md section 26). It is a working draft of commercial points, not legal advice. Whether to have a lawyer review it is the owner's choice.

## A. Private beta (v0.9), offered to one or two vendors
| Point | Draft term |
|---|---|
| Parties | The licensor, as the owner names it (individual or entity: owner input, as in the trademark dossier), and the vendor |
| Grant | A non-exclusive, non-transferable right to run suite v0.9 on the vendor's own drafting products, internally, for the beta term |
| Term | 90 days from signature |
| Fee | None for the beta. In exchange, the vendor gives written feedback on the harness and agrees to the result-statement rules below |
| Who runs it | The licensor runs the scoring, and the manual adjudication, on drafts the vendor submits under `HARNESS_SPEC.md`. The vendor receives the full report |
| Confidentiality | The vendor's drafts and reports are confidential to the vendor unless the vendor chooses to publish. Aggregated, anonymized beta findings may be used by the licensor to improve the suite |
| Result statements | The vendor may state its own results only with the suite version and the fixed limits statement (`HARNESS_SPEC.md` section 4). Not allowed: "certified", "compliant", "JRS approved", "prevents", "eliminates", "guarantees" |
| No mark | No logo or conformance mark is licensed at v0.9 |
| Suite content | The suite code and practice texts are already public in this repository. The beta licence covers the scoring service, the private-set runs once a sealed set exists, and the right to make result statements, not secrecy of public files |
| No warranty | The suite is pre-release. Scores may change between versions |
| Liability cap | Owner decision; a common default is fees paid, which is zero in the beta |
| Data | Vendors submit drafts of the public practice texts only, never real case files or personal data |
| Ending | Either side, on 14 days' written notice |
| Governing law | Owner decision |
