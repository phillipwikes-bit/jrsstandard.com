Local reviewer workspace

This tool shows a previously generated candidate reviewer packet so that you can record your own dispositions. It does not run the Engine, it does not judge the record, and it sends nothing anywhere. Nothing you do here is saved unless you export it.

A reviewer packet can contain quotations from the record. Treat the packet, this window and any export as confidential as the record itself.
