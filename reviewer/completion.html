Historical evaluation receipt

Retrieve an issued reviewer evaluation receipt

This page serves historical JRS reviewer evaluation receipts. It does not issue a new certificate, establish completion of the six training modules, or assess professional competence.

The issuing system must find both the code and the name in its private historical record before rendering a receipt. A correctly formatted code by itself is insufficient. The issuer-record date and title, if any, cannot be changed here.

If an older link cannot be verified, contact info@jrsstandard.com. No training accreditation or professional certification is provided through this route.

For current free training and its separately described self-reported participation record, visit JRS Reviewer Training.
