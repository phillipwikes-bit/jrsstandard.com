# Frozen demonstration capability matrix (internal)

**Package `JRS-FROZEN-DEMO-20261007-PR39` version 0.1.0. Status: `DEMO_PREPARATION_COMPLETE_NOT_RELEASED`.** Internal and not deployed (`*.md` is excluded by `.vercelignore`). Every case is synthetic, and every candidate output comes from the deterministic mock adapter. The replay shows what the local candidate software does with five frozen synthetic records. It shows nothing about real records, real models or readiness.

Each row names one capability and the synthetic case that shows it, then what the replay shows and what it does not. "Shown in local synthetic replay" means the frozen replay reproduces the behaviour byte for byte (`node tools/frozen-demo/verify-demo-manifest.mjs`). It is not a validation status.

## Reading the matrix
- Every limitation phrase is checked: `tools/frozen-demo/lib/verify.js` (section K) fails if a row is missing, if a row's last-but-one column names no limitation, or if a status names a release state.
- The replay is exact only within its fixed local configuration. A real model, a real record, an independent label, a deployment or a release decision is outside it.
